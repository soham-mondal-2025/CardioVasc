# CardioVision ML: Coronary Artery Disease & Multi-Vessel Stenosis Classification

This repository contains the machine learning pipeline trained to predict **Overall Coronary Artery Disease (CAD)** alongside vessel-specific stenosis status for the **LAD (Left Anterior Descending)**, **LCX (Left Circumflex)**, and **RCA (Right Coronary Artery)**.

## 🔬 Dataset & Clinical Context

- **Source**: UCI Machine Learning Repository / Mendeley Data: *Extension of Z-Alizadeh Sani Dataset* (DOI: `10.17632/9k56pwtvz9.1`).
- **Patient Cohort**: 303 patient records across 59 clinical, demographic, laboratory, ECG, and echocardiographic variables.
- **Leakage Prevention**: All vessel labels (`LAD`, `LCX`, `RCA`) and angiography outcome (`Cath`) were strictly excluded from model input features during training and evaluation to prevent target leakage.

---

## 🛠️ Key Methodological Innovations

1. **Clinical Feature Engineering**:
   - **TG/HDL Atherogenic Ratio**: Ratio of triglycerides to HDL cholesterol (established clinical biomarker for plaque formation).
   - **LDL/HDL Ratio & Non-HDL Cholesterol**: Direct indicators of atherogenic particle burden.
   - **ECG Ischemic Burden**: Combined index of Q Wave, ST elevation, ST depression, T-inversion, and poor R-wave progression.
   - **Age × Typical Chest Pain Interaction**: Exertional angina in patients older than 50 carries significantly elevated pre-test CAD probability.
   - **Echocardiographic Functional Score**: Integrates regional wall motion abnormalities (RWMA) and reduced ejection fraction (EF < 50%).

2. **Class Imbalance Handling**:
   - Synthetic Minority Over-sampling Technique (**SMOTE**) applied strictly to the training split folds, avoiding synthetic sample leakage into validation.

3. **Hybrid Ensemble Architecture**:
   - Soft Voting Ensemble combining:
     - **ExtraTrees Classifier**: High-variance mitigation and non-linear interactions.
     - **Random Forest Classifier**: Robust ensemble bagging.
     - **XGBoost Classifier**: Extreme gradient boosted decision trees with logarithmic loss regularization.

4. **Clinical Interpretability (SHAP)**:
   - Uses **TreeExplainer** to extract exact per-patient feature attributions (SHAP values), ranking which clinical measurements elevated or decreased cardiac risk.

## 🚀 How to Run the Training Pipeline

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Execute Training
```bash
python train_model.py
```

### 3. Output Artifacts
Trained weights and evaluation metrics will be exported into:
- `ml_pipeline/saved_models/cath_model.joblib` (Overall CAD model)
- `ml_pipeline/saved_models/lad_model.joblib` (LAD stenosis model)
- `ml_pipeline/saved_models/lcx_model.joblib` (LCX stenosis model)
- `ml_pipeline/saved_models/rca_model.joblib` (RCA stenosis model)
- `ml_pipeline/saved_models/shap_explainer.joblib` (TreeExplainer)
- `ml_pipeline/saved_models/metrics.json` (Full metrics report)
